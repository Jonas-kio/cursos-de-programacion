# Programación Funcional - Haskell

![Haskell](https://www.haskell.org/img/haskell-logo.svg)

Este repositorio contiene ejercicios, prácticas y ejemplos desarrollados durante el curso de **Programación Funcional** utilizando el lenguaje **Haskell**.

## 📚 Contenido

- **Funciones básicas:** definición y uso de funciones.
- **Tipos de datos:** tipos y firmas de funciones.
- **Listas:** operaciones y recorridos de listas.
- **Recursividad:** resolución de problemas mediante funciones recursivas.
- **Pattern Matching:** uso de patrones para definir funciones.
- **Funciones de orden superior:** `map`, `filter` y `takeWhile`.
- **Ejercicios prácticos:** problemas desarrollados durante el curso.

## 🛠️ Herramientas utilizadas

- **Haskell**
- **GHC / GHCi**
- **Cabal**
- **Visual Studio Code**

## ▶️ Cómo ejecutar

Abrir una terminal en la carpeta del proyecto y ejecutar:

```bash
