# 14 - Ejercicios finales

## Objetivo

Practicar todo el curso con ejercicios integradores.

## Ejercicios

1. Crear `mayorDeTres`.
2. Crear `esPalindromo`.
3. Crear `cantidadPares`.
4. Crear `sinNegativos`.
5. Crear `notasAprobadas`.
6. Crear `ultimoSeguro`.
7. Crear `Semaforo` y `accionSemaforo`.
8. Crear una funcion que cuente palabras de un texto.
9. Crear una funcion que calcule el promedio de una lista.
10. Crear un reporte completo para una lista de estudiantes.

## Metodo recomendado

Para cada ejercicio:

1. Escribir primero la firma de tipo.
2. Pensar casos especiales.
3. Elegir herramienta: `if`, guardas, pattern matching, recursion, `map`, `filter`, `foldr` o `Maybe`.
4. Probar en GHCi.
